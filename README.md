# Frontend Mentor - QR Code Card Component

## 📌 Overview

This is a simple front-end project built as part of a frontend practice challenge. The goal is to build a clean and responsive card component that displays a QR code, heading text, and a short description.

The project is built using only **HTML and CSS** in a single file.

---

## 🎯 Challenge Goal

The main objective of this project is to improve:

- Basic HTML structure
- CSS styling and layout
- Centering elements on the page
- Working with fonts and spacing
- Building a clean UI component

---

## 🛠️ Built With

- HTML5
- CSS3
- Google Fonts
- Flexbox (for centering content)
